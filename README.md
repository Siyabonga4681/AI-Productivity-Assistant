# ✨ Overview

FlowMate is a next-generation AI productivity platform designed to help professionals, students, administrators, and job seekers automate repetitive workplace tasks using Artificial Intelligence.

Instead of switching between multiple disconnected tools, FlowMate combines:

* Smart email generation
* Meeting summarisation
* AI task planning
* Research assistance
* Conversational AI support

…into one seamless productivity workspace.

FlowMate transforms time-consuming daily workflows into intelligent, automated experiences.

# 🎯 Prompt Engineering

FlowMate was designed with structured prompt engineering principles to ensure:

* Accurate outputs
* Context awareness
* Professional formatting
* Tone adaptability
* Fast AI responses

## 📧 Email Prompt

```txt
Write a {tone} email to a {recipient} about {context}.
Include:
- Clear subject line
- Professional opener
- 2–4 concise paragraphs
- Polite CTA
```

## 📝 Notes Prompt

```txt
Summarise this meeting transcript into:
- Key Points
- Decisions Made
- Action Items
- Risks
- Deadlines
```

## 📅 Planner Prompt

```txt
Classify these tasks using the Eisenhower Matrix.
Generate a time-blocked schedule with priorities and rationale.
```

## 🔍 Research Prompt

```txt
Summarise {topic} for a working professional in under 250 words.
Include:
- 3 key takeaways
- Simplified explanation
- 2 follow-up questions
```
